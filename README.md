## 📌 Overview / نظرة عامة

A lightweight, open-source Android app to benchmark and discover the fastest `DNS` servers with real-time latency indicators and one-click `Private DNS` setup. `DNS Radar` helps you find and apply the fastest and most reliable `DNS` servers for your network. It features real-time latency (ping) testing with color-coded status indicators, category filtering, and seamless Android `Private DNS` configuration.

تطبيق أندرويد مفتوح المصدر وخفيف لاختبار واكتشاف أسرع خوادم `DNS` مع مؤشرات حية لزمن الاستجابة وإعداد سهل لميزة `Private DNS` بنقرة واحدة. يساعدك تطبيق `DNS Radar` في العثور على أسرع خوادم الـ `DNS` وأكثرها استقراراً لشبكتك وتطبيقها بسهولة، مع ميزة فحص البينغ الحي بمؤشرات لونية ذكية، وفلترة حسب الفئات، وتكامل مباشر مع إعدادات الـ `Private DNS` في أندرويد.

## 🌟 Key Features / المميزات الرئيسية

### ⚡ English
- **Real-time Latency Ping:** Instant socket & `DoH` benchmark with precise millisecond response times.
- **Categorized Servers:** Filter by Gaming, Ad-blocking, Privacy & No-Logs, or Family Protection.
- **One-Click Android Setup:** Quick copy for `IPv4`, `IPv6`, and `DoT` (`Private DNS`) addresses with in-app setup guide.
- **Smart Latency Indicators:** Live visual indicators showing connection quality at a glance.
- **Privacy First & Offline Capable:** Zero trackers, zero unnecessary permissions, and full offline catalog caching.

### 🌟 بالعربية
- **قياس فوري لزمن الاستجابة:** فحص سريع عبر حزم الـ `Socket` وبروتوكول `DoH` بدقة أجزاء من الثانية.
- **تصنيف شامل للخوادم:** فلترة مخصصة للألعاب، حظر الإعلانات، الخصوصية الصارمة بدون سجلات، وحماية العائلة.
- **تفعيل بنقرة واحدة لأندرويد:** نسخ فوري لعناوين `IPv4` و `IPv6` و `DoT` الخاصة بـ `Private DNS` مع دليل إعداد تفاعلي.
- **مؤشرات استجابة ذكية:** دوائر حالة ملونة تعرض جودة الاتصال وسرعته بشكل فوري.
- **أولوية للخصوصية ودعم العمل بدون إنترنت:** بدون أي برمجيات تتبع، بدون أذونات غير ضرورية، مع حفظ محلي لقائمة الخوادم.

## 🚦 Latency Status / دليل مؤشرات السرعة

### ⚡ Status Breakdown (English)
| Indicator | Response Time | Description & Ideal Usage |
| :---: | :---: | :--- |
| 🟢 | **< 30ms** | Ultra fast — Ideal for competitive gaming and live streaming. |
| 🟡 | **30ms - 70ms** | Great performance — Perfect for everyday browsing and media. |
| 🟠 | **70ms - 130ms** | Moderate delay — Acceptable for standard web use. |
| 🔴 | **> 130ms** | Slow / High latency — Far routing servers, not recommended. |

### 🚦 تفصيل الحالات (بالعربية)
| المؤشر | زمن الاستجابة | الحالة والاستخدام الأمثل |
| :---: | :---: | :--- |
| 🟢 | **< 30ms** | استجابة فورية فائقة السرعة — مثالي للألعاب التنافسية والبث المباشر. |
| 🟡 | **30ms - 70ms** | سرعة ممتازة ومستقرة — مثالي للتصفح اليومي والمشاهدة. |
| 🟠 | **70ms - 130ms** | تأخير متوسط — مقبول للاستخدام اليومي العادي. |
| 🔴 | **> 130ms** | بطيء أو خوادم بعيدة جغرافياً — غير مستحسن. |
